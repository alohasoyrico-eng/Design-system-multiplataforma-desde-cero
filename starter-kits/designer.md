# Design System Designer Starter Kit

Use this path when shaping screens, states, or product flows.

1. Open `apps/docs`.
2. Start from templates, then patterns, then components.
3. Use `packages/content/content/catalog.json` to find artifact names and IDs.
4. Use `examples/prototyping/basic.html` as the smallest concrete UI reference.

Do not introduce visual rules directly in the docs app. Add reusable decisions to specs, content, tokens, or components.

Before handoff, ask a developer or agent to run `npm run audit`.
