# Fleet Manager Dashboard

Template web para gestores de flota. Demuestra: shell con sidebar, KPIs en mono, tabla CRUD (lista → detalle en panel lateral), tabs con filtros, búsqueda, badges vivos y dialog de confirmación. Todo compuesto con los primitives de `components/`.

Patrones cubiertos: **Dashboard/analytics** y **Listado + detalle (CRUD)**.
