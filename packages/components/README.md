# @design-system/components

Prototype-ready Package components for agents, designers, and developers.

Included starter components:

- Button
- Icon Button
- Input
- Select
- Card

Public contracts are exported from `./contracts`.

```js
import { componentContracts } from "./src/contracts.js";
```

Use these for quick prototypes and examples. Production behavior must still be checked against `packages/specs/specs/unison.system.json` and the audit gate.
