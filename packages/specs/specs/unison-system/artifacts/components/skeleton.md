# Skeleton

Skeleton reserves known content structure while data is loading, refreshing, or hydrating.

Use it when the future layout is known but the content is not ready. Use Progress Indicator instead when a real progress value exists. Replace Skeleton with content, empty state, or recovery as soon as the state changes.

Agents may choose the variant from future content shape: text, row, card, media, or chart. Humans should confirm the owning busy region, reduced motion behavior, and what replaces Skeleton on loaded or error states.
