# Progress Indicator

Progress Indicator communicates visible system work for uploads, imports, sync, refresh, and finite setup progress.

Use linear progress when the operation belongs to a row, card, upload zone, or section. Use circular progress only for compact inline status. Use indeterminate progress when the value is unknown, and never invent a percentage.

Agents may choose the geometry from value availability and space. Humans should confirm value source, completion/error messaging, reduced motion, and whether the system has become a larger loading or setup pattern.
